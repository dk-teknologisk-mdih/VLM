Detect the key structural keypoints of the {target_object} frame visible in
the image.

Place waypoints using the following rules:
1. JOINTS: Place one waypoint wherever two or more frame tubes meet,
   intersect, or are welded together.
2. ENDPOINTS: Place one waypoint at each terminal end of a frame tube
   (e.g., where an axle, headset, or seat post is inserted).
3. BENDS: Place one waypoint at any location where a single tube changes
   direction (curves or bends).

Constraints:
- Place exactly ONE waypoint per distinct location. If multiple rules
  apply to the same physical point (e.g., a joint that is also an
  endpoint), place only one waypoint there.
- Do NOT place waypoints on wheels, pedals, handlebars, seat, cables,
  or accessories — only on the structural frame tubes.
- Only include locations clearly visible in the image.

The answer should follow the YAML format:
- point: <point>
  label: <label>

Points are in [y, x] format normalized to 0-1000. Use short descriptive
labels for each waypoint describing the structural feature at that
location (e.g., "joint: top tube / down tube",
"endpoint: rear axle", "bend: seat stay").
